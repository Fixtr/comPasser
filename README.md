# 🧭 Compasser (컴패서)
"한국을 여행하는 사람들을 위한 AI 기반 다국어 로컬 동선 최적화 플래너"

Compasser는 한국을 여행하는 모든 사람(내/외국인 모두 포함)을 위해, 복잡한 여행 동선과 시간 계산을 AI와 지도가 알아서 해결해 주는 지능형 스마트 여행 플래너입니다. 사용자가 꼭 가고 싶은 필수 방문지(Anchor)만 입력하면, Google Gemini AI가 빈 시간의 동선을 최적화해 채워주고 Google Maps API가 지도 위에 생생하게 경로를 그려줍니다.

## ✨ 핵심 기능 (Key Features)

### 1. 🔐 보안 및 개인화: 통합 인증 시스템
- **다양한 로그인 방식**: Google 계정 기반의 간편 로그인뿐만 아니라, 이메일/비밀번호 기반의 자체 회원가입 기능을 제공합니다.
- **이메일 인증 보안**: 가입 시 Firebase Email Verification을 통해 인증 메일을 발송하며, 메일 내 링크를 클릭하여 인증을 완료한 유저만 서비스 이용이 가능하도록 보안 로직이 적용되어 있습니다.
- **개인화 UI (User Avatar)**: 로그인 시 상단 헤더 우측에 프로필 이미지(또는 기본 아바타)를 원형으로 표시하여 개인화된 경험을 제공합니다.
  - *Troubleshooting*: `referrerpolicy="no-referrer"` 속성과 Fallback 로직을 통해 이미지 로딩 오류 및 정책 차단을 완벽하게 방어합니다.
- **인증 라우팅 및 상태 관리**: `/home`(랜딩), `/login`(로그인), `/join`(회원가입) 경로를 명확히 분리했습니다. 특히 로그아웃 및 회원탈퇴 시 로컬/세션 스토리지에 남은 잔여 데이터(/plan 입력 정보, 튜토리얼 확인 기록 등)를 완벽하게 삭제하여 보안과 세션 정합성을 강화했습니다.
- **인증 에러 UX**: Firebase의 최신 보안 정책(Email Enumeration Protection)에 따라 `invalid-credential` 등 난해한 에러 코드를 분석하여, "이메일 또는 비밀번호가 올바르지 않습니다"와 같은 직관적인 한국어 알림창으로 변환해 제공합니다.
- **소셜 로그인 최적화**: 구글 로그인 버튼의 생명주기(Lifecycle) 이벤트를 보강하여 로그아웃 후 재로그인 시 버튼이 먹통이 되는 버그를 해결했으며, 기존 승인 계정에 대해서는 번거로운 선택창 없이 원클릭으로 접속되는 자동 로그인 흐름을 복구했습니다.
- **카카오 및 네이버 소셜 로그인 연동**: Firebase Cloud Functions와 Custom Token 발급 방식을 활용하여, 프론트엔드 팝업창 인증부터 백엔드 검증까지 안전하고 매끄러운 소셜 로그인 파이프라인을 구축했습니다.
  - *Security*: **Log Sanitization**을 통해 서버 및 클라이언트 로그에서 민감한 Token 및 유저 정보를 안전하게 마스킹 처리하여 보안성을 강화했습니다.
- **마이페이지(Profile & Settings) 중심의 통합 관리**: 기존 헤더에 분산되어 있던 '내 일정 보기'와 '계정 탈퇴' 기능을 하나의 전문적인 마이페이지(`/profile`)로 통합하고, **중첩 라우팅(Nested Routing)**을 적용했습니다.
  - **URL 기반 탭 시스템 (/profile/:tab)**: `/personal`, `/trips`, `/security` 등 직관적인 서브 경로를 도입하여 탭 상태를 URL과 완벽히 동기화했습니다. 이제 브라우저 '뒤로 가기'를 통해 이전 탭으로 이동할 수 있으며, 주소창에 직접 입력하여 특정 탭으로 즉시 진입(Deep Link)할 수 있습니다.
  - **Firestore 개인정보 연동 (Phase 1)**: 사용자의 확장된 프로필(휴대전화, 생년월일 등)을 저장하기 위해 `users/{uid}` 구조로 Firestore Database 연동을 완료했습니다.
  - **인라인 수정 UI**: `window.prompt` 없이 페이지 내에서 즉시 텍스트가 입력 필드로 변하는 세련된 인라인 폼 UI를 통해 사용자 정보를 수정할 수 있습니다.
  - **보안 강화**: 비로그인 사용자의 접근을 차단하는 Route Guard와 회원 탈퇴 시 실수를 방지하는 2단계 확인 모달(Confirm)을 적용했습니다. 특히 탈퇴 시 사용자의 모든 일정과 Firestore 프로필 데이터를 완벽하게 삭제하는 토탈 클린업 프로세스가 가동됩니다.
  - **안정성 강화 (Bug Fix)**: 
    - 신규 가입 유저가 마이페이지 진입 시 DB 데이터 부재로 인해 무한 '로딩 중...' 상태에 빠지던 치명적인 예외 처리 버그를 해결했습니다. 데이터가 없어도 '설정되지 않음'으로 안전하게 Fallback 됩니다.
    - **마이페이지 네비게이션 충돌 해결**: 마이페이지의 '내 여행 일정' 리스트에서 일정을 조회할 때, 더 이상 사용하지 않는 레거시 온보딩 모달("스마트한 여행 일정 만들기")이 렌더링되어 이벤트 버블링 및 비정상적인 라우팅(/plan 강제 이동)을 유발하던 문제 해결. 해당 레거시 코드를 전면 삭제하여 뷰어(/view/:id)로의 진입 안정성 100% 확보.
  - **실제 서비스 수준의 본인인증 (PortOne/KG이니시스)**: 휴대전화 입력 방식을 단순 타이핑에서 실제 한국 웹서비스 표준인 '본인인증(PASS/통신사)' 흐름으로 업그레이드했습니다.
    - **통합인증 팝업**: 포트원(PortOne) V1 SDK와 KG이니시스 채널을 연동하여 PASS, 토스, 카카오 등 다양한 간편인증 팝업을 제공합니다. (테스트 모드 완벽 지원)
    - **데이터 무결성**: 인증 성공 시에만 활성화되는 전용 인라인 폼을 통해 번호를 입력받으며, Firestore에 `phoneNumber`와 함께 `isVerified: true` 상태를 저장하여 신뢰할 수 있는 사용자 데이터를 확보합니다.
    - **인증 뱃지 UI**: 인증이 완료된 계정은 마이페이지에서 **(인증완료 ✅)** 뱃지가 표시되어 직관적인 피드백을 제공합니다.
  - **UX 최적화**: 마이페이지 진입 시 서비스 몰입을 위해 메인 히어로 헤더를 숨기고, 언제든 플래너로 복귀할 수 있는 '홈으로 돌아가기' 버튼을 배치했습니다.

### 2. 🤖 Gemini AI 기반 맞춤형 일정 자동 생성
- **다이내믹 일정 폼**: 하루의 시작/종료 장소를 지정하고, 반드시 방문해야 하는 '앵커 일정(Anchor Schedule)'을 원하는 만큼 `+`, `-` 버튼으로 자유롭게 추가할 수 있습니다.
- **스마트 빈칸 채우기**: 앵커 일정 사이의 붕 뜨는 시간과 동선을 AI가 분석하여, 최적의 맛집, 카페, 명소를 추천하고 완벽한 하루 일정을 완성합니다.

### 3. 📍 하이브리드 지도 연동 전략 (Hybrid Map Strategy)
Compasser는 지도의 역할을 **뷰어(Viewer)**와 **네비게이터(Navigator)**로 철저히 분리하여 최상의 사용성을 제공합니다.
- **뷰어 (Google Maps)**: 전체 동선을 다국어로 한눈에 보여주는 시각적 현황판 역할을 수행합니다. 각 장소 카드의 **[📍 리뷰 보기]** 버튼을 통해 상세 정보(평점, 사진, 영업시간 등)를 확인하는 용도로 활용됩니다.
- **네비게이터 (한국 최적화 딥링크)**: 실제 이동 시에는 일정 카드의 **[🗺️ 길찾기]** 버튼을 터치하여 **네이버 지도 / 카카오맵**을 실시간 내비게이션으로 실행합니다. (버튼 위치에 맞춘 지능형 팝업 UI 적용)

### 4. ⏱️ 사용자 친화적 타임라인 UI 및 대시보드
- **일정 요약 대시보드 (Trip Summary Card)**: 타임라인 최상단에 총 방문 장소 수, 전체 시간 범위, 카테고리별 일정(핵심, 명소, 맛집, 레저)을 한눈에 요약해 보여주는 세련된 대시보드를 제공합니다.
- **이동 수단 시각화 (Transit Icons)**: 버스, 지하철, 기차, 택시, 도보 등 이동 수단별 전용 컬러 아이콘과 뱃지 UI를 적용하여 동선 파악의 가독성을 극대화했습니다.
- **상세 타임라인**: 일정이 진행되는 순서대로 번호가 매겨진 카드를 제공하며, 구간별 소요 시간과 거리를 직관적으로 표시합니다.

- **깜빡임 없는 (Flicker-free) UX**: 화면 전환 시 History API 기반의 Navigation First 패턴과 `requestAnimationFrame`, `sessionStorage`를 활용하여 데이터 로드와 DOM 업데이트를 완벽히 분리, 60fps에 달하는 쾌적한 화면 전환을 제공합니다.
- **동적 파라미터 라우팅 (/view/:id) 도입**: 정규 표현식을 활용한 고도화된 라우팅 엔진을 구현하여 개별 여행 일정에 고유 URL을 부여했습니다. 이제 특정 일정의 링크를 공유하거나 브라우저 새로고침을 해도 데이터가 유지됩니다. 
- **Deep Linking 및 상태 유지**: URL의 ID를 기반으로 Firestore(`itineraries` 컬렉션)에서 실시간 데이터를 조회하도록 개선하여, 아키텍처의 안정성과 확장성을 확보했습니다.
- **안정적인 이미지 내보내기 (Bug Fix)**: `html2canvas` 라이브러리를 활용한 DOM 캡처 중, 최신 CSS 색상 함수(예: `color(display-p3)`)를 파싱하지 못해 이미지 다운로드가 실패하는 렌더링 엔진 호환성 문제를 해결했습니다. 캡처 프로세스 시작 시 문제가 되는 최신 CSS 속성과 불필요한 UI 요소(버튼 등)를 `ignoreElements` 콜백 및 임시 스타일 변환(Cleanup 로직 포함)을 통해 필터링하여 다운로드 기능을 완벽하게 복구했습니다.
- **8-Page 전문 라우팅**: `/home`(랜딩), `/login`(로그인), `/join`(회원가입), `/verify`(인증), `/plan`(플래너), `/view`(결과 - 임시), `/view/:id`(결과 - 고유), `/profile`(마이페이지 & 중첩 탭)로 이어지는 체계적인 서비스 경로를 구축했습니다.

### 6. 📂 내 일정 저장 및 마이페이지 통합 관리
- 생성된 마음에 드는 일정을 계정에 연동하여 안전하게 저장할 수 있습니다.
- 새로운 **마이페이지(/profile)**의 '내 여행 일정' 탭에서 모든 저장된 기록을 한눈에 확인하고, 원클릭으로 다시 지도로 불러오거나 삭제 관리할 수 있습니다.
- **자연스러운 불러오기**: 리스트에서 일정을 선택하면 즉시 결과 화면으로 전환되며 기존 일정을 완벽히 복원합니다.

### 7. 🌍 완벽한 다국어(i18n) 지원
- 한국어(ko)와 영어(en)를 동시에 지원하는 시스템을 갖추었습니다.
- 상단 **언어 토글** 버튼 조작 시 페이지 새로고침 없이, 기존 문서 DOM과 이벤트 리스너를 파괴하지 않는 안전한 텍스트 업데이트 로직이 적용되어 UI와 AI 프롬프트가 동적으로 전환됩니다.

### 8. 🛡️ 인앱 브라우저(WebView) 방어 로직
- 카카오톡 등 앱 내장 브라우저에서 Google 로그인 시 발생하는 403(`disallowed_useragent`) 에러를 방지합니다.
- 안드로이드에서는 Chrome Intent를 활용해 외부 브라우저로 강제 리다이렉션하며, iOS에서는 사파리 외부 실행을 유도하는 맞춤형 안내 모달을 제공합니다.

### 9. 🗺️ 지도 및 UI 사용성 개선
- **경로 방향성 강화**: 지도 위에 그려지는 경로상에 보라색 화살표를 시각화하여 이동 방향을 명확히 안내합니다.
- **검색 지역 최적화**: 구글 맵스 장소 검색 자동완성(Autocomplete)의 범위를 한국(KR)으로 제한하여 불필요한 해외 검색 결과를 차단했습니다.
- **즉시 초기화**: 입력 폼 전체를 한 번에 초기화(Reset)할 수 있는 버튼을 추가해 사용 편의성을 극대화했습니다.

### 10. 🔒 데이터베이스 보안 규칙 (Security Rules) 분리 적용
- **공유용 데이터(`shared_itineraries`)**: 카카오톡 등으로 공유된 단축 URL 접근 시 누구나 읽을 수 있도록 읽기 권한을 전체 허용했습니다.
- **개인 보관용 데이터(`itineraries`)**: 사용자가 개인 계정에 저장한 일정은 철저히 로그인한 본인만 접근(CRUD)할 수 있도록 보안 규칙을 엄격하게 분리했습니다.

### 11. 📊 데이터 분석 및 로깅 (Google Analytics 4)
- **사용자 행동 추적 (Custom Events)**: AI 일정 생성(`generate_itinerary_click`), 일정 저장(`save_itinerary_click`), 카카오톡 공유(`share_kakao_click`), 다국어 전환(`change_language`) 등 핵심 인터랙션을 세밀하게 추적합니다.
- **SPA 가상 페이지 뷰**: 바닐라 JS의 History API 네비게이션(popstate)을 감지하여 리로드 없이 화면이 변경되어도 정확하게 `page_view` 이벤트를 GA4로 전송합니다.
- **보안/환경 변수 분리**: GA4 측정 ID(`VITE_GA_MEASUREMENT_ID`) 등 주요 설정값은 코드에 직접 노출하지 않고 `.env` 파일로 주입시켜 관리하며 Git 저장소 공유를 원천 차단했습니다.

### 12. 📱 모바일 웹앱 설치 (PWA) 및 온보딩 UX
- **홈 화면 추가**: Web App Manifest(`manifest.json`)와 Service Worker(`sw.js`) 연동을 통해 사용자가 터치 한 번으로 모바일 및 데스크탑 홈 화면에 바로가기 앱을 설치(Add to Home Screen)할 수 있습니다.
- **네이티브 앱 경험**: 모바일 사용성 강화를 위해 동적 테마 색상(theme-color)을 적용하고, 모바일 OS 표준에 맞춘 고해상도 규격 아이콘(192x192, 512x512)을 탑재하여 이질감 없는 사용 환경을 제공합니다.
- **지능형 온보딩 모달**: 유저가 로그인 후 처음 `/plan` 페이지에 진입할 때만 나타나는 튜토리얼 모달을 제공합니다. `localStorage(hasSeenTutorial)` 연동을 통해 최초 1회만 노출되며, 비디오 플레이어와의 레이아웃 겹침 문제를 해결하기 위한 최상위 `z-index(99999)` 처리가 완료되었습니다.

### 13. 🎨 세련된 UI/UX 디자인 고도화 (Polishing)
- **반응형 3열 레이아웃**: `/home` 페이지의 기능 소개 카드가 데스크탑에서는 가로 3열, 모바일에서는 1열로 최적화되어 노출됩니다.

### 14. 📢 로딩 대기 시간 활용 제휴 광고 배너 캐러셀
- **타겟 맞춤형 배너**: AI 일정 생성 대기 중 한국 여행 외국인 관광객 타겟의 가상 제휴 광고(eSIM, AREX, 한복 대여, K-Food 투어, T-money 카드) 배너를 자동 슬라이드로 노출합니다.
- **부드러운 전환 애니메이션**: `opacity`와 `translateY` 기반의 fade-in/out 효과로 3.5초마다 배너가 자연스럽게 전환되며, 하단 인디케이터 도트로 현재 위치를 표시합니다.
- **광고 모듈 리팩토링 (Separation of Concerns)**: 메인 렌더링 로직에 하드코딩되어 있던 제휴 마케팅(Affiliate) 배너 데이터를 별도의 설정 파일(`/src/config/ads.js`)로 완벽히 분리했습니다. 이를 통해 UI 컴포넌트의 복잡도를 낮추고, 개발 지식이 없는 마케터도 손쉽게 제휴 링크와 배너 속성(bgColor, icon 등)을 교체할 수 있는 확장성 높은 구조를 확립했습니다.
- **메모리 안전**: 로딩 완료/실패 시 `clearInterval`을 호출하여 메모리 누수를 방지하며, 다크모드에서도 시인성이 유지되도록 별도 스타일을 적용했습니다.

### 15. 💡 지능형 실용 정보(Quick Info) 고도화
- **구조화된 AI 데이터 스키마**: 기존의 단순 문자열 꿀팁을 객체(Object) 형태로 업그레이드했습니다. AI가 비용(`estimatedCost`), 시간(`operatingHours`), 현지 팁(`localTip`)을 명확히 구분하여 생성하도록 프롬프트를 고도화했습니다.
- **3단 구조화 UI (Quick Info Panel)**: 각 장소 카드 내부에 💰(비용), 🕐(시간), 💡(팁) 아이콘을 활용한 세련된 3줄 레이아웃을 적용하여 정보 밀도와 가독성을 동시에 확보했습니다.
- **완벽한 하위 호환성 (Backward Compatibility)**: 데이터 포맷 변경 시 발생할 수 있는 에러를 방지하기 위해, 과거에 생성된 문자열 기반 데이터는 자동으로 기존 1줄 레이아웃으로 렌더링되도록 지능형 분기 로직(Fallback)을 적용했습니다.

### 16. 🛡️ 안정적인 AI 파이프라인 (Fault-Tolerant AI Architecture)
외부 AI 서버의 장애 상황에서도 서비스가 멈추지 않도록 강력한 안정성 확보 로직이 구축되어 상용 서비스 수준의 신뢰성을 제공합니다.
- **지수 백오프 기반 자동 재시도**: Gemini API 호출 중 일반적인 네트워크 오류 시 자동 재시도를 수행합니다.
- **Fast Fail & 즉시 모델 폴백**: 503(과부하), 429(할당량) 에러 감지 시 0초 대기로 즉시 백업 모델(`gemini-2.0-flash-lite`)로 우회하여 응답성을 확보합니다.
- **최후 방어선 Mock Data**: 모든 API 실패 시에도 앱이 멈추지 않도록 입력값을 기반으로 한 Fail-safe 일정을 자동 생성합니다.

### 17. ⚡ 극한의 속도 최적화 (Extreme Performance Optimization)
- **지능형 다이나믹 로딩**: 생성 대기 중 3초 간격으로 순환하는 텍스트 UI를 통해 체감 대기 시간을 혁신적으로 줄였습니다.
- **완벽한 병렬 처리 (Parallel Execution)**: 구글 맵스 지오코딩 및 경로 계산 로직(Directions)을 `Promise.all` 기반의 병렬 구조로 리팩토링하여 네트워크 병목을 제거했습니다.
- **초기화 락(Init Lock) 패턴**: 수십 개의 병렬 요청이 발생해도 SDK 로드는 단 한 번만 수행되도록 설계되어 불필요한 오버헤드를 원천 차단합니다.

## 🏛️ 아키텍처 하이라이트: DDD & Vibe Coding 최적화
Compasser는 빠른 MVP 구현에 그치지 않고, AI 보조 코딩(Vibe Coding)의 효율성을 극대화하고 유지보수성을 높이기 위해 **도메인 주도 설계(DDD: Domain-Driven Design)** 아키텍처를 도입했습니다.

- **관심사의 분리 (Domain Separation)**: 코드를 화면 단위가 아닌 비즈니스 개념 단위로 분리했습니다.
  - 📁 `auth/`: Firebase Google Auth 기반의 사용자 인증 도메인 (랜딩 페이지 포함)
  - 📁 `planner/`: 사용자 폼 입력 및 Gemini AI 통신 도메인 (429 Error Handling 및 Debounce 적용)
  - 📁 `itinerary/`: 생성된 일정 데이터를 타임라인 UI로 렌더링하는 도메인
  - 📁 `profile/`: 사용자 정보, 일정 히스토리, 계정 보안 설정을 담당하는 마이페이지 도메인
  - 📁 `map/`: Google Maps 렌더링, 지오코딩, 길찾기 서비스 로직 도메인
- **네이티브 브릿지 (Mobile Layer)**: Capacitor를 통해 웹의 비즈니스 로직을 손상시키지 않고 네이티브 기능과 결합합니다.
- **유비쿼터스 언어 (Ubiquitous Language)**: AI의 환각(Hallucination)을 방지하기 위해 `AnchorSchedule`, `TransitRoute`, `ItineraryPlan` 등 명확한 비즈니스 용어 사전을 정의하고 코드 전반에 강제했습니다.
- **컨텍스트 트리거 (Context Triggers)**: 각 도메인 폴더 최상단에 `COMMAND_GUIDE.md`를 배치하여, AI 및 협업 개발자가 해당 도메인의 비즈니스 규칙을 즉각적으로 파악할 수 있도록 설계했습니다.

## 🚀 Getting Started (로컬 실행 방법)

### 1. 웹 개발 모드 (Vite)
1. 저장소를 클론하고 패키지를 설치합니다.
   ```bash
   git clone https://github.com/Fixtr/hackerton.git
   cd hackerton
   npm install
   ```
2. `.env` 파일을 생성하고 API 키를 입력합니다. (`VITE_MAPS_API_KEY`, `GEMINI_API_KEY`)
3. 개발 서버를 실행합니다.
   ```bash
   npm run dev
   ```

### 2. 모바일 앱 개발 모드 (Capacitor)
웹 프로젝트를 빌드한 후 네이티브 플랫폼에 동기화하여 실행합니다.
- **iOS 실행**: 
  ```bash
  npm run cap:run:ios
  ```
- **Android 실행**: 
  ```bash
  npm run cap:run:android
  ```
- **변경 사항 동기화**: 프로젝트 수정 후 웹 빌드 결과를 앱에 반영합니다.
  ```bash
  npm run cap:sync
  ```

## 🌐 Deployment (배포 방법)

### Cloudflare Pages (SPA 권장)
본 프로젝트는 Cloudflare Pages를 통해 배포 중이며, SPA(Single Page Application) 라우팅을 위해 다음 설정이 적용되어 있습니다.

1.  **Vite 설정**: `vite.config.js`의 `base`가 `/` (절대 경로)로 설정되어야 합니다.
2.  **라우팅 규정**: `public/_redirects` 파일에 `/* /index.html 200` 규칙이 포함되어 있어, 모든 서브 경로 접속 시에도 `index.html`이 정상적으로 로드됩니다.
3.  **자동 배포**: GitHub의 `main` 브랜치에 코드를 Push 하면 Cloudflare Pages에서 자동으로 빌드 및 배포가 진행됩니다.
