# 경로 생성 품질 기준선

각 사례의 단일 응답을 평가했다. 평균 성공률이나 모델 간 우열을 의미하지 않는다.

앱 보정은 실제 prepareGeneratedPlaces → enforcePlannerConstraints 순서를 재사용한다.
Maps 캡처의 실제 장소·경로 조회 및 시간 보정 후 결과를 함께 평가했다.
지각·도착은 실제 Google 경로가 없으면 미측정이며, 일정 자체의 충돌이 확인되면 위반이다. 체류시간은 현재 일정표 기준이다.

| 사례 | 모델 | 생성 초 | 원본→보정→지도 후 짧은 체류 | 잘못된 검색 기준점 | 잘못된 방문 목적 | 장소 확인/대상 | 경로 확인/대상 | 필수 일정 도착 | 종료 시각 |
|---|---|---:|---:|---:|---:|---|---|---|---|
| day-airport | gemini-2.5-flash-lite | 3.6 | 0 → 0 → 0 | 0 | 0 | 4/4 | 6/6 | 통과 | 통과 |
| day-anchor | gemini-2.5-flash-lite | 4.4 | 0 → 0 → 0 | 0 | 0 | 2/2 | 4/4 | 통과 | 통과 |
| day-short | gemini-2.5-flash-lite | 2.1 | 0 → 0 → 0 | 0 | 0 | 2/2 | 3/3 | 해당 없음 | 통과 |
| day-tight-anchors | gemini-2.5-flash-lite | 3.3 | 1 → 0 → 미측정 | 0 | 0 | 미측정 | 미측정 | 미측정 | 미측정 |
| four-day-anchors | gemini-2.5-flash-lite | 5.2 | 0 → 0 → 0 | 0 | 0 | 6/6 | 14/14 | 통과 | 통과 |
| four-day-food | gemini-2.5-flash-lite | 5.2 | 0 → 0 → 0 | 0 | 0 | 7/7 | 11/11 | 해당 없음 | 통과 |

장소 확인은 선택 방문만 센다. 경로 확인은 고정 장소까지 포함한 인접 구간 전체를 센다. 일부 구간이 미확인인 경우 도착 가능 판정은 미측정으로 남긴다.
상세 항목·시간·토큰은 [report.json](report.json), 정확한 입력·프롬프트·응답은 같은 폴더의 *.capture.json에 보관한다.
