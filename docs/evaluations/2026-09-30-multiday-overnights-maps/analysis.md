# 숙소 연결 3박 4일 실지도 재측정

기존 [두 Gemini 생성 원문](../2026-09-30-multiday-overnights/analysis.md)을 변경하지 않고,
최소 체류 보정 후 Google Places와 Directions로 실제 장소와 인접 이동을 조회했다.
연속 조회 중 식도락 사례 첫날 Places 검색이 실패하여 그 결과를 제외하고,
해당 사례를 단독으로 다시 조회해 성공한 캡처만 저장했다.

| 항목 | 필수 일정·세 숙소 | 식도락·같은 숙소 |
|---|---:|---:|
숙소 경계 일치 | 3/3 | 3/3 |
선택 방문 장소 확인 | 7/7 | 8/8 |
인접 이동 확인 | 15/15 | 12/12 |
날짜 간 같은 Place ID 재방문 | 0 | 0 |
최소 체류 위반(원문→보정→지도 후) | 1→0→0 | 0→0→0 |
고정 일정 도착·일일 종료 | 통과 | 종료 통과, 고정 일정 없음 |

식도락 생성 원문에서 2·4일차에 반복된 `디저트 카페` 문구는 각각 호텔과
서울역을 검색 중심으로 삼았다. 지도에서 서로 다른 장소 ID로 확인됐다.
목적 문구의 반복만으로 실제 재방문이라고 판단해 삭제하지 않는다.

필수 일정 사례의 첫날 선택 방문 두 곳은 실제 이동시간과 15시 고정 일정에
맞추는 과정에서 빠졌다. 고정 일정을 유지한 채 성립하는 하루가 남았다.
두 사례씩 한 번 측정한 결과이며 다른 입력이나 미래 교통편의 성공률을 뜻하지 않는다.
개별 장소·구간·시간은 같은 폴더의 캡처와 [평가 보고서](report.md)에 있다.
